# AgroPulse

Real-time crop price platform from, it aggregates APMC mandi, buyer & FPO prices for farmers. Features ML price forecasting (Linear Regression), comparisons, optimal sell alerts via Flask, MongoDB & Bootstrap UI. Empowers fair trade, cuts distress sales. ## 🚀 Features
- **Live Price Aggregation**: APMC mandis, private buyers, FPOs
- **ML Predictions**: Linear Regression for trends & optimal sell times
- **Smart Dashboard**: Location-based comparisons, alerts, recommendations
- **Simple Workflow**: Enter crop/quantity/location → Get insights [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/attachments/93724425/1c5a6343-2497-4f77-9869-353ee8bfffc7/AgroPulse.pdf)
